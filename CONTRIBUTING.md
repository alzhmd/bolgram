# 🤝 Contributing to SyncPay BD

Thank you for your interest! Here's how to contribute:

## 🚀 Ways to Contribute
- 🐛 Report bugs via Issues
- ✨ Add new MFS payment method support
- 📝 Improve documentation
- 🧪 Add test cases

## 📋 PR Process
1. Fork → Branch → Code → PR
2. Branch naming: `feature/your-feature` or `fix/bug-name`
3. Commit style: `✨ Add: feature` or `🐛 Fix: bug`
