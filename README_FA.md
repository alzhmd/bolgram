# بولگرام — درگاه کارت به کارت با تأیید خودکار

این پروژه fork شدهٔ [SyncPay BD](https://github.com/jahidulislamseo/syncpay-bd) است. همهٔ قابلیت‌های آن (پنل پذیرنده، پنل ادمین، API و وب‌هوک HMAC، اپ اندروید Flutter با صف آفلاین، SDKهای PHP/Node/Python، افزونهٔ WooCommerce و WHMCS) حفظ شده و فقط بخش‌های مخصوص ایران جایگزین شده است.

## چه چیزی برای ایران تغییر کرد
- **پارسر پیامک بانک‌های ایران** (`src/parsers/ir`): قالب واقعی ملت، ملی، تجارت، پاسارگاد، رسالت، پارسیان، بلو، شهر، مهر ایران و خاورمیانه، به‌همراه پارسر عمومی برای بقیهٔ بانک‌ها (سامان، سپه، صادرات، آینده، …). از اعداد فارسی، تاریخ شمسی و ریال/تومان پشتیبانی می‌کند.
- **مبلغ یکتا**: هر فاکتور باز یک مبلغ منحصربه‌فرد می‌گیرد (مبلغ پایه + چند تومان). همین مبلغ پیامک واریز را به همان فاکتور وصل می‌کند. مبالغ فاکتورهای ۲۴ ساعت اخیر دوباره استفاده نمی‌شوند تا واریزهای دیرهنگام یا تکراری به سفارش اشتباه نخورند.
- **امنیت**: پیامک رمز پویا/کد تأیید نه در اپ ارسال می‌شود و نه در سرور ذخیره می‌شود. پیامک برداشت نادیده گرفته می‌شود. واریز از فرستندهٔ ناشناس (مثلاً شمارهٔ موبایل جعلی) خودکار تأیید نمی‌شود. پیامک تکراری هم با شناسهٔ پایدار مسدود می‌شود.
- **صفحهٔ پرداخت فارسی** (`public/checkout.html`): اول از مشتری می‌پرسد با کارت کدام بانک پرداخت می‌کند. اگر کارت هم‌بانک داشته باشید همان را نشان می‌دهد. دکمهٔ کپی، تایمر، تأیید لحظه‌ای (SSE) و بازگشت خودکار به فروشگاه دارد.
- **ربات فروشنده در تلگرام و بله**: ساخت فاکتور با فرستادن مبلغ، افزودن/خاموش/حذف کارت، گزارش پرداخت‌ها، بررسی واریزی‌های بی‌صاحب (وصل به فاکتور یا رد) و اعلان لحظه‌ای هر پرداخت. در تلگرام از Rich Message استفاده می‌شود (جدول فشرده `is_compact`، دکمه‌های رنگی `RichBlockButtons`، دکمهٔ کپی داخل متن `RichTextButton`، نقل‌قول بازشو `expandable_blockquote`)؛ در بله همان منوها متن و دکمهٔ شیشه‌ای است. اتصال هر گفتگو با کد یک‌بارمصرف ۱۰ دقیقه‌ای از پنل؛ پیام حاوی شمارهٔ کارت بلافاصله از گفتگو پاک می‌شود و با تغییر رمز، اتصال ربات‌ها هم باطل می‌شود.
- **اپ اندروید**: فیلتر فرستنده‌های بانک ایران به‌جای bKash/Nagad.

## بخش‌ها
- **پنل فروشنده** `/panel/`: داشبورد، فاکتورها، واریزی‌های بی‌صاحب، گزارش‌ها، لینک پرداخت (و لینک ارزی)، کیف پول کارمزد، کارت‌ها، پلن‌ها، دستگاه‌ها، اپلیکیشن، ربات تلگرام و بله، افزونه‌ها و API، وب‌هوک، نماد اعتماد، همکاران با نقش، دعوت دوستان، پشتیبانی، آموزش، نظر من، اعلان‌ها، تنظیمات.
- **پنل مالک** `/owner/`: داشبورد کل سرویس، فروشگاه‌ها (تعلیق، خروج اجباری)، پلن‌ها، تنظیمات مالی، کیف پول‌ها و شارژها، تیکت‌ها، نماد اعتماد، نظرها، اعلان همگانی، وب‌هوک‌های ناموفق، محتوای سایت، آزمایشگاه پیامک بانک، گزارش فعالیت، سلامت سیستم.
- **صفحه‌های عمومی**: پرداخت `/checkout.html`، لینک پرداخت `/l/<نام>`، نماد اعتماد `/trust/<نام فروشگاه>`.
- **سایت معرفی** در `website/` (Cloudflare Pages). محتوا، پلن‌ها و نظرها را زنده از `API_BASE` می‌خواند (`website/public/assets/js/config.js`).
- **اپ اندروید** در `zinipay_forwarder/` و **افزونهٔ ووکامرس** در `integrations/woocommerce/`.

## راه‌اندازی (سرور لینوکس، Node.js 22)
```bash
git clone <repo> && cd bolgram
npm ci && cp .env.example .env
npm run build && npm start        # پورت 4000 (پشت Nginx/Caddy با HTTPS)
```
این مقادیر `.env` را حتماً پر کنید:
- `JWT_SECRET` (رشتهٔ تصادفی بلند)
- `CARD_ENC_KEY` (`openssl rand -hex 32`؛ هرگز عوضش نکنید)
- `ADMIN_EMAIL` و `ADMIN_PASSWORD` (ورود به `/owner/`)
- `PUBLIC_BASE_URL=https://دامنهٔ-شما`
- `NODE_ENV=production`

بعد:
1. **پیامک ورود:** در پنل SMS.IR یک قالب Verify با پارامتر `CODE` بسازید و `SMSIR_API_KEY` و `SMSIR_TEMPLATE_ID` را بگذارید.
2. **ربات‌ها (اختیاری):** `TELEGRAM_BOT_TOKEN`/`TELEGRAM_BOT_USERNAME` و `BALE_BOT_TOKEN`/`BALE_BOT_USERNAME`. سرورِ داخل ایران برای تلگرام رله لازم دارد (`TELEGRAM_API_BASE`).
3. **شارژ کیف پول:** یک فروشگاه عادی برای خود سرویس بسازید، کارت و گوشی‌اش را وصل کنید، و در `/owner/` ← «تنظیمات مالی» آن را «فروشگاه سرویس» انتخاب کنید. شارژ کیف پول فروشنده‌ها با همان سازوکار کارت‌به‌کارت به این فروشگاه واریز و خودکار تأیید می‌شود.
4. **ساخت فاکتور از سایت دیگر:** `POST /api/v1/payment/create` با کلید API از «افزونه‌ها و API». جزئیات و نمونه‌کدها در `website/public/docs.html`.

## امنیت (مهم)
- **ورود:** ورود، نقش‌ها (مالک، مدیر، حسابدار، صندوق‌دار، فقط مشاهده) و دسترسی‌ها همگی سمت سرور بررسی می‌شوند.
- **کارت‌ها:** شمارهٔ کارت‌ها رمزنگاری‌شده ذخیره می‌شود و فقط ۴ رقم آخر نمایش داده می‌شود.
- **پیامک:** پیامک از فرستندهٔ غیربانکی هرگز خودکار تأیید نمی‌شود و به صف بررسی می‌رود. پیامک تکراری دوباره حساب نمی‌شود و OTP و برداشت نادیده گرفته می‌شوند.
- **وب‌هوک:** امضای وب‌هوک `X-Bolgram-Signature: t=<unix>,v1=<hmac>` است که روی `${t}.${body}` محاسبه می‌شود. اگر اختلاف زمان بیشتر از ۵ دقیقه بود، درخواست را رد کنید.

## اپ اندروید
- **ساخت:** فایل `.github/workflows/android.yml` با هر push نسخهٔ APK را می‌سازد و در Actions قرار می‌دهد. برای امضای واقعی، Secretهای `ANDROID_KEYSTORE_BASE64`، `ANDROID_KEY_ALIAS`، `ANDROID_KEY_PASSWORD` و `ANDROID_STORE_PASSWORD` را در GitHub تعریف کنید.
- **آدرس سرور:** با متغیر `BOLGRAM_SERVER` تنظیم می‌شود.
- **لینک دانلود در پنل:** متغیرهای `ANDROID_APK_URL`، `ANDROID_APK_SHA256` و `ANDROID_APP_VERSION` را در `.env` بگذارید.
- **فروشگاه‌ها:** Google Play برای مجوز SMS فرم «Permissions Declaration» می‌خواهد؛ برای بازار و مایکت همین APK کافی است.
