درگاه کارت‌به‌کارت با تأیید خودکار برای ووکامرس؛ پول مستقیم به کارت خودتان واریز می‌شود.

== Description ==

بولگرام پیامک بانکی گوشی شما را می‌خواند و هر فاکتور را با یک مبلغ یکتا به واریز مشتری وصل می‌کند. این افزونه ووکامرس را به بولگرام وصل می‌کند:

* ساخت فاکتور با API نسخهٔ ۱ و انتقال مشتری به صفحهٔ پرداخت بولگرام
* تأیید خودکار پرداخت با وب‌هوک امضاشده (HMAC-SHA256) و استعلام دوباره از سرور
* تکمیل سفارش فقط یک‌بار (idempotent) حتی اگر وب‌هوک چند بار برسد
* پشتیبانی از ریال، تومان و هزار ریال/هزار تومان
* سازگار با HPOS (ذخیرهٔ سفارش‌ها در جدول‌های اختصاصی)

== Installation ==

1. فایل zip را از «افزونه‌ها > افزودن > بارگذاری افزونه» نصب و فعال کنید (یا پوشهٔ `bolgram-gateway` را در `wp-content/plugins` بگذارید).
2. در ووکامرس > تنظیمات > پرداخت > «بولگرام»، آدرس سرور و کلید API را وارد کنید.
3. در پنل بولگرام، بخش «وب‌هوک»، کلید امضا را نمایش دهید و در تنظیمات افزونه بگذارید.
4. درگاه را فعال کنید و یک سفارش آزمایشی ثبت کنید.

آدرس وب‌هوک را لازم نیست دستی ثبت کنید؛ افزونه آن را همراه هر فاکتور می‌فرستد (`/?wc-api=bolgram_webhook`). آدرس باید روی https و عمومی باشد.

== Frequently Asked Questions ==

= پرداخت انجام شد ولی سفارش «در انتظار پرداخت» مانده است =
در پنل بولگرام، بخش «وب‌هوک» و «سابقهٔ ارسال» را ببینید. اگر خطا دارد، کلید امضا یا دسترسی سرور وردپرس را بررسی کنید و «ارسال دوباره» را بزنید.

= واحد پول فروشگاه ریال یا تومان نیست =
درگاه فقط برای IRR، IRT، IRHR و IRHT نمایش داده می‌شود.
